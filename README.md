**🎮 Stone Paper Scissors Game (Python)**

This project is a simple command-line version of the classic Stone-Paper-Scissors game built using Python.

**📌 Features**
Interactive menu system to start or exit the game
User vs Computer gameplay
Randomized computer choices using Python’s random module
Instant result display (Win / Lose / Draw)
Continuous play until the user exits
**🧠 How It Works**
The user selects stone, paper, or scissors
The computer randomly selects one of the three options
The program compares both choices and determines the result:
Stone beats Scissors
Paper beats Stone
Scissors beats Paper
The result is displayed on the screen
**📂 Project Structure**
game.py → Contains the core game logic
main.py → Handles the menu and user interaction
**▶️ How to Run**
Run the main file.
Choose an option from the menu to play or exit
